Run Local-First on Your Phone / Laptop

Leaving QR is designed for airplane-mode, local-first operation. The host device runs an embedded Node.js HTTP server. The database is authenticated and encrypted on disk using AES-256-GCM with PBKDF2 (100,000 iterations). No cloud accounts or external servers required.

1. Clone & Install

git clone https://github.com/westkitty/Private_Load.git cd Private_Load npm install

2. Start Local Server

npm start

3. Test Suite

npm test
